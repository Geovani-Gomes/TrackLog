# 🚚 MiniLog - Sistema de Análise de Entregas

## 📌 Descrição
Projeto de logística desenvolvido em Python utilizando SQLite.  
O sistema analisa dados de entregas e gera informações como tempo médio, atrasos e desempenho por cidade.

---

## 🎯 Funcionalidades
- Cadastro de entregas no banco de dados
- Cálculo do tempo de entrega
- Identificação de entregas atrasadas
- Média de tempo por cidade

---

## 👨‍💻 Tecnologias utilizadas
- Python
- SQLite
- Pandas

---

1. Abra o terminal na pasta do projeto
